# HalfSnap

Left / right window halves. Accessibility only. No drag-snap, no prefs, no updater.

## Hotkeys

| Shortcut | Action |
|----------|--------|
| `⌥←` | Left half |
| `⌥→` | Right half |

## Run

```bash
./build.sh
open HalfSnap.app
```

Grant **Accessibility** when prompted (or menu → Accessibility Settings…).

## Stop

Menu bar `◫` → Quit HalfSnap, or `pkill -x HalfSnap`.
